1. 파일 구성
--------------------------------------------------------------------------------
  counter_app.py          프로그램 소스
  counter_app.spec        PyInstaller 빌드 설정
  USB_serial_check.py     연결된 COM 포트 / USB 시리얼 번호 확인용 도구
  dist\counter_app.exe    빌드된 실행 파일 (서버에는 이 파일만 복사하면 됨)

  프로그램 실행 후 exe와 같은 폴더에 자동 생성되는 파일
  counter_config.json                     카드 목록 / 포트 / 자동 연결 여부 저장
  counter_log_<장비명>_<날짜>.csv          1초 단위 카운트 기록 (날짜별 파일)

2. 개발 PC에서 실행하기 (Python)
--------------------------------------------------------------------------------
  (1) 필요한 패키지 설치 (명령 프롬프트)

      pip install PyQt5 pymodbus pyserial

  (2) 실행

      python counter_app.py


--------------------------------------------------------------------------------
3. 실행 파일(exe) 만들기
--------------------------------------------------------------------------------
  ※ 소스(counter_app.py)를 수정했다면 반드시 다시 빌드해야 exe에 반영됩니다.

  (1) PyInstaller 설치 (최초 1회)

      pip install pyinstaller

  (2) 빌드 (counter_app.py가 있는 폴더에서 실행)

      python -m PyInstaller --noconsole --onefile counter_app.py

  (3) 결과물: dist\counter_app.exe


--------------------------------------------------------------------------------
4. 서버 PC에 설치하기
--------------------------------------------------------------------------------
  (1) 프로그램 폴더 만들기
      예) C:\CounterApp\

      ※ "C:\Program Files" 아래에는 두지 마세요.
         쓰기 권한이 없어 설정 파일과 CSV 로그가 저장되지 않습니다.

  (2) dist\counter_app.exe 를 C:\CounterApp\ 에 복사

  (3) USB-시리얼 변환기(SCM-US48I) 드라이버 설치 후 장비 연결
      - 장치 관리자 > 포트(COM & LPT) 에서 COM 번호 확인
      - 여러 대일 때는 USB_serial_check.py 로 시리얼 번호를 확인한 뒤
        counter_app.py 의 DEVICE_MAP 에 등록하면 포트 목록에 장비 이름이 표시됩니다.

  (4) counter_app.exe 실행 → 카드마다 이름/포트 지정 → [▶ 연결 시작]
      - 연결에 성공한 카드는 설정 파일에 "자동 연결"로 기록되어,
        다음 실행(재부팅 포함) 때 자동으로 다시 연결됩니다.
      - [■ 연결 끊기]를 누른 카드는 다음 실행 때 자동 연결하지 않습니다.

  (5) COM 포트 번호 고정 (권장)
      USB를 다른 포트에 꽂으면 COM 번호가 바뀌어 자동 연결이 실패합니다.
      - 장비는 항상 같은 USB 포트에 꽂아 두세요.
      - 필요하면 장치 관리자 > 해당 COM 포트 > 속성 > 포트 설정 > 고급
        > "COM 포트 번호"에서 번호를 직접 지정할 수 있습니다.

5. 부팅 시 자동 실행 설정
--------------------------------------------------------------------------------
  이 프로그램은 화면(창)이 있는 프로그램이므로 "Windows에 로그인된 상태"에서
  실행되어야 합니다. 따라서 [5-1 사전 설정]으로 자동 로그인을 켠 뒤,
  [5-2 방법 A] 또는 [5-3 방법 B] 중 "하나만" 설정하세요.
  (두 가지를 모두 설정하면 프로그램이 2개 실행되어 COM 포트 충돌이 납니다.)

  권장: 방법 B (작업 스케줄러) - USB 장치 인식을 기다리는 지연 실행이 가능


  ---------------------------------------------------------
  5-1. 사전 설정 (서버 PC에서 1회)
  ---------------------------------------------------------
  (1) Windows 자동 로그인
      a. Win + R → netplwiz 입력 → 확인
      b. 프로그램을 실행할 사용자 선택
      c. "사용자 이름과 암호를 입력해야 이 컴퓨터를 사용할 수 있음" 체크 해제
      d. 확인 → 해당 계정 암호 입력

      ※ 체크박스가 보이지 않으면 (Windows 10/11):
         설정 > 계정 > 로그인 옵션 >
         "보안 향상을 위해 ... Windows Hello 로그인만 허용" 을 끔 → 다시 netplwiz 실행
      ※ 또는 Microsoft 공식 도구 "Autologon" (Sysinternals) 을 사용해도 됩니다.
      ※ 자동 로그인은 누구나 PC를 사용할 수 있게 되므로,
         프로그램 실행 전용 로컬 계정을 만들어 사용하는 것을 권장합니다.
         (로그인 후 Win + L 로 화면을 잠가도 프로그램은 계속 동작합니다.)

  (2) 절전 모드 끄기 (관리자 권한 명령 프롬프트)

      powercfg /change standby-timeout-ac 0
      powercfg /change hibernate-timeout-ac 0

      ※ 모니터 끄기는 상관없습니다. "절전(대기)"만 꺼져 있으면 됩니다.

  (3) USB 절전 끄기 (USB-시리얼 연결이 끊기는 것 방지)
      a. 제어판 > 전원 옵션 > 설정 변경 > 고급 전원 관리 옵션 설정 변경
         > USB 설정 > USB 선택적 절전 모드 설정 → "사용 안 함"
      b. 장치 관리자 > 범용 직렬 버스 컨트롤러 > 각 "USB 루트 허브" > 속성
         > 전원 관리 탭 > "전원을 절약하기 위해 컴퓨터가 이 장치를 끌 수 있음" 체크 해제

  (4) (선택) 정전 후 자동 켜짐
      BIOS 설정에서 "Restore on AC Power Loss" (또는 AC Power Recovery)
      항목을 "Power On" 으로 설정하면 정전 복구 시 PC가 자동으로 켜집니다.
      (메뉴 이름은 메인보드 제조사마다 다릅니다.)

  (5) (선택) Windows 업데이트 자동 재시작 시간 조정
      설정 > Windows 업데이트 > 고급 옵션 > 사용 시간 에서
      라인 가동 시간대를 사용 시간으로 지정해 두면 가동 중 재시작을 줄일 수 있습니다.
      (재시작되더라도 자동 로그인 + 자동 실행으로 수집이 다시 시작됩니다.)


  ---------------------------------------------------------
  5-2. 방법 A - 시작프로그램 폴더 (가장 간단)
  ---------------------------------------------------------
  a. C:\CounterApp\counter_app.exe 를 마우스 오른쪽 클릭 → "바로 가기 만들기"
  b. Win + R → shell:startup 입력 → 확인  (시작프로그램 폴더가 열림)
  c. 만든 바로 가기를 이 폴더로 이동
  d. 재부팅하여 로그인 후 프로그램이 자동으로 뜨는지 확인

  해제: shell:startup 폴더에서 바로 가기 삭제

  ※ 로그인 직후 바로 실행되므로, USB 장치 인식이 늦으면 "연결 실패"가 뜰 수 있습니다.
     이런 경우 [▶ 연결 시작]을 누르거나 방법 B 를 사용하세요.


  ---------------------------------------------------------
  5-3. 방법 B - 작업 스케줄러 (권장)
  ---------------------------------------------------------
  [화면에서 설정하기]
  a. Win + R → taskschd.msc 입력 → 확인
  b. 오른쪽 "작업 만들기..." 클릭 ("기본 작업 만들기" 아님)

  c. [일반] 탭
     - 이름: 카운터 모니터링
     - "사용자가 로그온할 때만 실행" 선택
       (※ "로그온 여부에 관계없이 실행"을 고르면 창이 화면에 보이지 않습니다)

  d. [트리거] 탭 → 새로 만들기
     - 작업 시작: "로그온할 때"
     - 특정 사용자: 자동 로그인하는 계정
     - 고급 설정 > "작업 지연 시간" 체크 → 30초
       (USB-시리얼 장치가 인식될 시간을 줌. 연결 실패가 잦으면 1분으로)

  e. [동작] 탭 → 새로 만들기
     - 동작: 프로그램 시작
     - 프로그램/스크립트: C:\CounterApp\counter_app.exe
     - 시작 위치(옵션):   C:\CounterApp

  f. [조건] 탭
     - "컴퓨터의 AC 전원이 켜져 있는 경우에만 작업 시작" 체크 해제 (노트북인 경우)

  g. [설정] 탭  ← 중요
     - "다음 시간 이상 작업이 실행되면 중지" 체크 해제
       (기본값 3일 → 체크되어 있으면 3일 뒤 프로그램이 강제 종료됩니다!)
     - "작업이 이미 실행 중이면 적용되는 규칙": "새 인스턴스 시작 안 함"

  h. 확인 → 재부팅하여 로그인 30초 후 프로그램이 뜨는지 확인

  [PowerShell 로 한 번에 설정하기] (위 a~h 와 동일한 내용)
  자동 로그인 계정으로 로그인한 상태에서 "관리자 권한 PowerShell"을 열고
  아래 내용을 붙여 넣으세요. (exe 경로가 다르면 첫 줄만 수정)

      $exe = "C:\CounterApp\counter_app.exe"
      $action    = New-ScheduledTaskAction -Execute $exe -WorkingDirectory (Split-Path $exe)
      $trigger   = New-ScheduledTaskTrigger -AtLogOn -User "$env:USERDOMAIN\$env:USERNAME"
      $trigger.Delay = "PT30S"
      $principal = New-ScheduledTaskPrincipal -UserId "$env:USERDOMAIN\$env:USERNAME" -LogonType Interactive -RunLevel Limited
      $settings  = New-ScheduledTaskSettingsSet -ExecutionTimeLimit ([TimeSpan]::Zero) -MultipleInstances IgnoreNew -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
      Register-ScheduledTask -TaskName "CounterMonitor" -Action $action -Trigger $trigger -Principal $principal -Settings $settings

  바로 실행해 보기:  Start-ScheduledTask -TaskName "CounterMonitor"
  해제:              Unregister-ScheduledTask -TaskName "CounterMonitor" -Confirm:$false

  5-4. 자동 실행 최종 점검 목록
  ---------------------------------------------------------
  [ ] 수동 실행해서 모든 카드를 연결한 뒤 "수집 중" 상태 그대로 둠
  [ ] 자동 로그인 설정 완료
  [ ] 절전 모드 / USB 절전 끔
  [ ] 방법 A 또는 B 중 "하나만" 설정
  [ ] 재부팅 → 로그인 → 프로그램 자동 실행 → 카드가 자동으로 "수집 중"이 되는지 확인
  [ ] C:\CounterApp\ 에 오늘 날짜 CSV 파일이 생기고 계속 기록되는지 확인

6. 동작 방식 참고
--------------------------------------------------------------------------------
  - 통신 설정: 9600 bps, Even, Data 8, Stop 1, Slave ID 1 (CT6Y 기본값)
  - 1초마다 Holding Register 0~1 (32비트 카운트 값)을 읽어 화면 표시 및 CSV 기록
  - [0 리셋]: Coil 1 에 ON 을 보내 카운터를 0 으로 초기화 (연결 중에만 가능)
  - 설정 파일과 CSV는 항상 exe 가 있는 폴더에 저장됩니다.
    (자동 실행 시 작업 폴더가 달라도 동일)
  - 설정은 카드 추가/삭제, 연결/해제 할 때마다 즉시 저장됩니다.
    정전이나 강제 재부팅 후에도 마지막 상태로 복구됩니다.
  - 장비 통신은 카드마다 별도 스레드에서 처리되어, 한 장비가 응답하지 않아도
    화면이나 다른 장비 수집이 멈추지 않습니다.

7. 문제 해결
--------------------------------------------------------------------------------
  증상: 부팅 후 카드가 "연결 실패"
    → USB 장치 인식 전에 실행됨. 방법 B 의 지연 시간을 1분으로 늘리거나
      [▶ 연결 시작]을 눌러 다시 연결
    → COM 번호가 바뀌었는지 확인 (4-(5) 참고)

  증상: "응답 오류" 배지 (연결은 됐지만 값이 안 들어옴)
    → 카운터의 통신 설정(9600/Even/8/1, 국번 1), RS485 배선(A/B) 확인

  증상: 프로그램이 2개 실행됨 / 한쪽이 연결 실패
    → 방법 A 와 방법 B 를 동시에 설정했는지 확인하고 하나만 남김

  증상: 며칠 뒤 프로그램이 저절로 꺼짐
    → 작업 스케줄러 [설정] 탭의 "다음 시간 이상 작업이 실행되면 중지" 해제 (5-3 g)

  증상: 자동 실행은 되는데 창이 보이지 않음
    → 작업 스케줄러 [일반] 탭을 "사용자가 로그온할 때만 실행"으로 변경

  증상: 설정이 매번 초기화됨 / CSV가 생기지 않음
    → exe 폴더에 쓰기 권한이 있는지 확인 (Program Files 아래에 두지 말 것)
    → 하단 상태바에 "설정 저장 실패" / "CSV 저장 실패" 메시지가 있는지 확인

  증상: exe 실행 시 "Windows의 PC 보호" 파란 창
    → "추가 정보" → "실행" 클릭 (직접 빌드한 exe라 서명이 없어서 나오는 경고)
